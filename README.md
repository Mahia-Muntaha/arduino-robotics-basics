# Arduino Robotics Basics

A collection of beginner-level robotics projects and experiments
developed using Arduino.

## Projects

| Project | Description |
|---|---|
| LED Blink | Basic Arduino digital output |
| Ultrasonic Sensor | Distance measurement using HC-SR04 |
| Servo Motor | Servo position control |
| Line Following Robot | Basic autonomous robot |
| Obstacle Avoiding Robot | Robot using ultrasonic sensing |

## Hardware & Tools

- Arduino
- Ultrasonic Sensor
- Servo Motor
- DC Motors
- Motor Driver
- IR Sensors
- Arduino IDE

## Purpose

This repository documents my learning journey in Arduino programming,
robotics, and basic embedded systems.
