# LED Blink

A basic Arduino project demonstrating digital output control by blinking an LED at a fixed interval.

## Objective

To understand how Arduino controls a digital output pin and how timing can be implemented using `delay()`.

## Components

* Arduino
* LED
* Resistor
* Breadboard
* Jumper wires

## Working Principle

The Arduino sets the LED pin as an output. The LED is turned ON for one second and then turned OFF for one second, creating a continuous blinking pattern.

## Code

The complete implementation is available in [`LED_Blink.ino`](./LED_Blink.ino).

## Concepts

* `pinMode()`
* `digitalWrite()`
* `delay()`
* Digital output
