# RGB LED

An Arduino project demonstrating the control of the red, green, and blue channels of an RGB LED to produce different colors and blinking patterns.

## Objective

To understand how individual RGB channels can be controlled using Arduino digital output pins to create different colors and patterns.

## Components

* Arduino
* RGB LED
* Resistors
* Breadboard
* Jumper wires

## Working Principle

An RGB LED contains three individual color channels: red, green, and blue.

By controlling these channels independently, different colors can be produced. The project includes several blinking patterns, including individual color sequences and combined colors such as yellow and lavender.

## Current Pattern

The current program runs the lavender blinking pattern.

Other available patterns in the code include:

* RGB sequence
* GRB sequence
* Yellow
* Lavender
